# 샌드 업무 앱

주문서 만들기, 고객 문의 답장 도우미, 예약 관리표를 한곳에서 열 수 있어요.

- 공개 앱 목록: https://gkak00940-netizen.github.io/1110/
- 이 컴퓨터의 앱 목록: http://localhost:8000/

## 수정한 내용을 공개 사이트에 반영하기

이 작업 폴더에서는 `main`에서 커밋하면 GitHub에도 자동으로 올리도록 설정했어요. GitHub에 올라간 내용은 공개 사이트에 자동으로 반영돼요. 반영에는 잠시 시간이 걸릴 수 있어요.

인터넷 연결이나 GitHub 로그인이 풀리면 커밋은 컴퓨터에 남고 업로드만 실패할 수 있어요. 그때는 로그인과 인터넷을 확인하고 ‘변경 사항 동기화’를 눌러 주세요.

이 자동 업로드 설정은 지금 컴퓨터의 이 작업 폴더에 적용돼요. 다른 컴퓨터에 내려받을 때는 별도로 설정해야 해요. 설정 명령은 `git config core.hooksPath .githooks`예요.

## 저장 내용에 관해

각 앱의 입력 내용과 팀 코드는 사용하는 브라우저에 저장돼요. 팀 코드는 파일이나 GitHub에 넣지 않아요. 이 컴퓨터에서 입력한 내용과 공개 사이트에서 입력한 내용은 서로 별도로 저장돼요.

답장 도우미는 공개 사이트에서 팀 코드를 다시 연결해 주세요. 고객에게 보낼 답장은 내용을 확인한 후 사용해 주세요.

첫 버전에는 `v1` 표시를 붙였어요.
